学习傅里叶变换

2026-06-118 min read (3630 words)
目录

初衷是想要为我的合成器写一个EQ均衡器，不满足于一般的推导，这里来仔细研究下。

其实我的作法也有关键部分没有完成。写到哪里算哪里：

一般的推导这篇文章写得很好，但这些推导的主要问题有二：

  1. 无法解决“任意一个周期函数都可以展开为不同频率的余弦函数的线性组合”的假设
  2. 推广到非周期时使用的是“假设一个周期无限长的函数” 想要解决第一点比较棘手，还没想好怎么做，但是沿着新的思路有利于更直观地描述傅里叶变换。

对于问题一可以这样描述：我们知道不同频率的余弦函数的线性组合可以构成很多周期函数，但这些周期函数可以张成到整个空间吗？
既然提到空间，首先得问：这是什么空间？
我们选定的空间是L2([−π,π])L^2([-\pi,\pi])的线性空间（向量空间），在这之上定义内积与范数（公理略）：

⟨f,g⟩=12π∫−ππf(x)g(x)‾dx \langle f, g\rangle = \frac{1}{2\pi}\int_{-\pi}^{\pi}f(x)\overline{g(x)}dx

∥f∥=⟨f,f⟩=12π∫−ππ∣f(x)∣2dx \|f\| = \langle f, f\rangle = \sqrt{\frac{1}{2\pi}\int_{-\pi}^{\pi}|f(x)|^2 dx}

由Riesz-Fischer定理，L2L^2 空间关于范数∥⋅∥\|·\|完备，也就是说L2([−π,π])L^2([-\pi,\pi])是Hilbert空间。
考察函数族en(x)=einx,n∈Z,einx∈L2([−π,π])e_n(x) = e^{inx}, n \in Z, e^{inx} \in L^2([-\pi,\pi])：
n≠m,k=n−m∈Z:n \neq m, k = n-m \in Z:

⟨en,em⟩=12π∫−ππei(n−m)xdx=12π[eikxik]−ππ=12π⋅2isin(kπ)ik=sin(kπ)kπ=0 \langle e_n, e_m\rangle = \frac{1}{2\pi}\int_{-\pi}^{\pi}e^{i(n-m)x}dx = \frac{1}{2\pi}[\frac{e^{ikx}}{ik}]_{-\pi}^{\pi} = \frac{1}{2\pi} · \frac{2i sin(k\pi)}{ik} = \frac{sin(k\pi)}{k\pi} = 0

n=m:n = m:

⟨en,en⟩=12π∫−ππei(n−n)xdx=1 \langle e_n, e_n\rangle = \frac{1}{2\pi}\int_{-\pi}^{\pi}e^{i(n-n)x}dx = 1

由此得enn∈Z{e_n}_{n \in Z}是L2([−π,π])L^2([-\pi,\pi])的规范正交系。
而对于任意f∈L2f \in L^2，定义第n个傅里叶系数：

f^(x)=⟨f,einx⟩=12π∫−ππf(x)e−inxdx \hat{f}(x) = \langle f, e^{inx}\rangle = \frac{1}{2\pi}\int_{-\pi}^{\pi}f(x)e^{-inx}dx

这不需要依赖于可分解，是直观的ff在ene_n的分量；但L2([−π,π])L^2([-\pi,\pi])是无限维的，而任意VN=span{e−N,...,eN}V_N = span\{e_{-N}, ..., e_N\}只是一个有限维的子空间；那么尝试表达在N阶三角多项式中，哪一个在L2L^2意义下距ff最近：
设线性组合：

PN=∑∣n∣≤Ncnen P_N = \sum_{|n|\leq N}c_n e_n

∥f−PN∥2=⟨f−PN,f−PN⟩=∥f∥2−⟨f,PN⟩−⟨f,PN⟩‾+∥PN∥2 \|f-P_N\|^2 = \langle f-P_N, f-P_N\rangle = \|f\|^2 - \langle f, P_N\rangle - \overline{\langle f, P_N\rangle} + \|P_N\|^2

⟨f,PN⟩=⟨f,∑∣n∣≤Ncnen⟩=∑∣n∣≤Ncnˉ⟨f,en⟩=∑∣n∣≤Ncnˉf^(x) \langle f, P_N\rangle = \langle f, \sum_{|n|\leq N}c_n e_n\rangle = \sum_{|n|\leq N}\bar{c_n}\langle f, e_n\rangle = \sum_{|n|\leq N}\bar{c_n}\hat{f}(x)

∥PN∥2=⟨∑∣n∣≤Ncnen,∑∣n∣≤Ncnen⟩=∑∣n∣≤Ncncnˉ⟨en,en⟩=∑∣n∣≤N∣cn∣2 \|P_N\|^2 = \langle \sum_{|n|\leq N}c_n e_n, \sum_{|n|\leq N}c_n e_n\rangle = \sum_{|n|\leq N} c_n\bar{c_n}\langle e_n, e_n\rangle = \sum_{|n|\leq N}|c_n|^2

代入：

∥f−PN∥2=∥f∥2−∑∣n∣≤Ncnˉf^(x)−∑∣n∣≤Ncnf^(x)‾+∑∣n∣≤N∣cn∣2 \|f-P_N\|^2 = \|f\|^2 - \sum_{|n|\leq N}\bar{c_n}\hat{f}(x) - \sum_{|n|\leq N}c_n\overline{\hat{f}(x)} + \sum_{|n|\leq N}|c_n|^2

整理：

∣cn∣2−cnˉf^(x)−cnf^(x)‾=∣cn−f^(x)∣2−∣f^(x)∣2 |c_n|^2 - \bar{c_n}\hat{f}(x) - c_n\overline{\hat{f}(x)} = |c_n - \hat{f}(x)|^2 - |\hat{f}(x)|^2

代入得：

∥f−PN∥2=∥f∥2−∑∣n∣≤N∣f^(x)∣2+∑∣n∣≤N∣cn−f^(x)∣2 \|f-P_N\|^2 = \|f\|^2 - \sum_{|n|\leq N}|\hat{f}(x)|^2 + \sum_{|n|\leq N}|c_n - \hat{f}(x)|^2

前两项是项数N决定的系统误差，第三项在所有系数取f^(x)\hat{f}(x)时为0：

0≤∥f−PN∥2=∥f∥2−∑∣n∣≤N∣f^(x)∣2 0 \leq \|f-P_N\|^2 = \|f\|^2 - \sum_{|n|\leq N}|\hat{f}(x)|^2

正好推出Bessel不等式：

∑∣n∣≤N∣f^(x)∣2≤∥f∥2 \sum_{|n|\leq N}|\hat{f}(x)|^2 \leq \|f\|^2

（Bessel不等式可以在希尔伯特空间中更一般性地证明，所以其实可以用它反推范数收敛）

(补记：直观地说，∥f−PN∥2\|f-P_N\|^2的主要作用在于确定规范正交系外其他向量参与的运算是否拥有我们所需的良好性质， 比如当两个单位向量互相靠近时，他们的内积是否收敛到1。衡量误差最直观的方法便是直接计算两个向量的差的范数平方)

接下来就是规范正交系地完备性证明，这里实在是力竭了，暂时略过；
其效果是证明三角多项式在L2L^2中稠密，即存在三角多项式逼近f，证明完备性后才能证明Parseval等式（通过完备性获得另一边与Bessel夹出），由此得到limN→∞∥f−PN∥2=0lim_{N\to \infty}\|f-P_N\|^2 = 0，即具体地，由傅里叶级数逼近f。到这里便解决了问题1。

最后为了推广到非周期，需要f^(x)\hat{f}(x)延拓到L1，再做一遍与L2中相似的事。

最后推到离散就比较简单：
从冲激函数（时域采样）(想象一个梳子)：

xs(t)=∑n=−∞+∞x(nTs)δ(t−nTs) x_s(t) = \sum_{n=-\infty}^{+\infty}x(nT_s)\delta(t-nT_s)

傅里叶变换得：

X(ω)=∑n=−∞+∞x[n]e−iωn X(\omega) = \sum_{n=-\infty}^{+\infty}x[n]e^{-i\omega n}

再对频域采样：ωk=2πkN,k=0,1,2,...,N−1\omega_k = \frac{2\pi k}{N}, k = 0, 1, 2, ..., N-1

X[k]=∑n=0N−1x[n]e−i2πkNn X[k] = \sum_{n=0}^{N-1}x[n]e^{-i\frac{2\pi k}{N} n}

写成矩阵形式：
设α=e−i2πN\alpha = e^{-i\frac{2\pi}{N}}：

[X0X1X2⋮XN−1]=[111⋯11αα2⋯αN−11α2α4⋯α2(N−1)⋮⋮⋮⋱⋮1α(N−1)α2(N−1)⋯α(N−1)(N−1)][x0x1x2⋮xN−1] \begin{bmatrix} X_0 \\ X_1 \\ X_2 \\ \vdots \\ X_{N-1} \\ \end{bmatrix} = \begin{bmatrix} 1 & 1 & 1 & \cdots & 1 \\ 1 & \alpha & \alpha^2 & \cdots & \alpha^{N-1} \\ 1 & \alpha^2 & \alpha^4 & \cdots & \alpha^{2(N-1)} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & \alpha^{(N-1)} & \alpha^{2(N-1)} & \cdots & \alpha^{(N-1)(N-1)} \\ \end{bmatrix} \begin{bmatrix} x_0 \\ x_1 \\ x_2 \\ \vdots \\ x_{N-1} \\ \end{bmatrix}

对于每行可以视作这样的多项式：

f(x)=a0+a1x+a2x2+a3x3+a4x4+a5x5+a6x6+a7x7G(x)=a0+a2x+a4x2+a6x3H(x)=a1+a3x+a5x2+a7x3f(x)=G(x2)+x∗H(x2) \begin{aligned} f(x) = a_0 + a_1x + a_2x^2 + a_3x^3 + a_4x^4 + a_5x^5 + a_6x^6 + a_7x^7 \\ G(x) = a_0 + a_2x + a_4x^2 + a_6x^3 \\ H(x) = a_1 + a_3x + a_5x^2 + a_7x^3 \\ f(x) = G(x^2) + x*H(x^2) \end{aligned}

令ωN=e−i2πN\omega_N = e^{-i\frac{2\pi}{N}}，则：

Xk=f(ωnk)=G(ωn2k)+ωnk∗H(ωn2k)=G(ωn/2k)+ωnk∗H(ωn/2k)Xk+n/2=f(ωnk+n/2)=G(ωn2k+n)−ωnk+n/2∗H(ωn2k+n)=G(ωn2k)−ωnk∗H(ωn2k)=G(ωn/2k)−ωnk∗H(ωn/2k) \begin{aligned} X_k = f(\omega_n^k) = G(\omega_n^{2k}) + \omega_n^k * H(\omega_n^{2k}) \\ = G(\omega_{n/2}^k) + \omega_n^k * H(\omega_{n/2}^k) \\ X_{k+n/2} = f(\omega_n^{k+n/2}) = G(\omega_n^{2k+n}) - \omega_n^{k+n/2} * H(\omega_n^{2k+n}) \\ = G(\omega_n^{2k}) - \omega_n^k * H(\omega_n^{2k}) \\ = G(\omega_{n/2}^k) - \omega_n^k * H(\omega_{n/2}^k) \\ \end{aligned}

由此可知，欲计算n个f，只需要计算n/2对GH；G与H可以通过同样方法继续展开，展开log⁡2n\log_2 n次后得到n个常数系数，之后再两两线性组合即可完成变换。还有一个好处是每对fk,fk+n/2f_k, f_{k+n/2}都对应一对GH，所以理论上可以完全复用x的空间变换到X，没有增长。
最直观的方式是用递归实现，每层将偶数项左排，奇数项右排，拆解到最小单元再一层层组合回来，每次都在一个tmp数组中将f的项排列好再拷贝回f；但这样空间复杂度翻倍，且每个项数都会被搬运log2nlog_2 n次；有没有更好的置换方式呢？

那么在这里注意到（迫真），每个项在重排后的序列中的位置正好是它原位的二进制表示的翻转（翻转宽度为最大项数的最小二进制表示宽度）。比如x1x_1为001，反转后就是100，也就是4。这一点实际上意外地好理解：

以两种方式看待位置编号：第一种是奇偶数，第二种是每位表示分类在左边还是右边。按前一种理解，最小位为0是是偶数，1时是奇数；后一种则是该区间编号最大位为0时为左区间，1时为右区间，这正好和我们的交换规则对应；二分一次后，每个区间的编号总位数减少一位，而同类元素的相对位置不变，所以可以直接除2，作为当前所在区间的局部编号，往复此过程就会发现这是个二进制表示逐位轮换的过程。以x3x_3为例：

第一次二分，011是奇数，所以排在右边，于是重排后编号的最后一位设1：
局部编号：01x 最终编号：1xx
第二次二分，局部坐标变为01，是奇数，排在右边，子区间编号最后一位设1：
局部编号：0xx 最终编号：11x
同上，设0：
局部编号：xxx 最终编号：110

既然已经提前排好，那么就从递归改为递推实现。

void butterfly(double complex *dat, size_t size) {
	static size_t rev_size = 0;
	static size_t rev[CACHE_SIZE] = {0};
	if (rev_size != size) {
		rev_size = size;
		for (size_t i = 0; i < size; i+=2) {
			rev[i] = rev[i / 2] / 2;
			rev[i + 1] = rev[i] | (size / 2);
		}
	}
	for (size_t i = 0; i < size; i++) {
		if (i < rev[i]) {
			double complex tmp = dat[i];
			dat[i] = dat[rev[i]];
			dat[rev[i]] = tmp;
		}
	}

}

void _fft(double complex *dat, size_t size, int symbol) {
	butterfly(dat, size);
	for (size_t i = 2; i <= size; i *= 2) {
		double complex step = ccos(2 * M_PI / i) + symbol * csin(2 * M_PI / i) * I;
		for (size_t j = 0; j < size; j += i) {
			double complex w = 1.0;
			for (size_t k = j; k < j + i / 2; k++) {
				double complex u = dat[k];
				double complex t = w * dat[k + i / 2];
				dat[k] = u + t;
				dat[k + i / 2] = u - t;
				w *= step;
			}
		}
	}
	if (symbol == -1) {
		for (size_t i = 0; i < size; i++) {
			dat[i] /= size;
		}
	}
}
